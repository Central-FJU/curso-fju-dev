## Objetivos

- Entender que, no nível mais básico, tudo é luz acesa (1) ou apagada (0)
- Ver como padrões de bits viram números, e números viram letras, cores e sons
- Saber o que é um algoritmo: entrada → instruções passo a passo → saída
- Perceber que a forma de resolver importa (busca página por página × dividir para conquistar)
- Usar variáveis para guardar informações
- Tomar decisões com condicionais (`if` / `else`)
- Repetir tarefas com laços (loops)
- Escrever o primeiro programa em Python

## Revisão rápida

1. O que é um algoritmo?
2. Para que serve uma variável?
3. O que faz um comando `if` / `else`?

<details>
<summary>Respostas</summary>

1. Uma receita: instruções claras e sequenciais que transformam uma entrada na saída desejada.
2. É uma caixa com nome onde guardamos um dado. A caixa continua a mesma, mas o conteúdo pode mudar.
3. Escolhe um caminho com base em uma pergunta de "sim ou não": se (`if`) for verdade, faz uma coisa; senão (`else`), faz outra.

</details>
