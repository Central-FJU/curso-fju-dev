# Aula 01 – Hardware e Software

**Como o Computador Pensa: do Hardware ao Código** — uma jornada do físico ao lógico.

🎥 **Gravação:** _(adicionar link da gravação)_

## Objetivos

- Diferenciar hardware (o corpo) de software (a mente)
- Entender os papéis de CPU, RAM, cache e disco (a analogia do escritório)
- Compreender por que o computador usa 0 e 1, e como o binário vira texto (ASCII)
- Conhecer o papel do sistema operacional
- Ver como portas lógicas (AND, OR, NOT) tomam decisões
- Seguir o caminho de um código, do teclado até a tela

## Revisão rápida

1. Se a energia cair, quem perde os dados?
2. Quem organiza os programas na memória?
3. O que são fisicamente os 0s e 1s?

<details>
<summary>Respostas</summary>

1. A RAM (a "mesa"). O disco (o "arquivo") guarda tudo para sempre.
2. O sistema operacional (o "gerente do escritório").
3. Transistores: interruptores microscópicos — ligado = 1, desligado = 0.

</details>
