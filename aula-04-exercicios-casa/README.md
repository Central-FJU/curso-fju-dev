# Aula 04 – Exercícios para casa

Nesta aula, **você** é quem vai descobrir como cada programa funciona.

## O que fazer

Para **cada** arquivo da pasta [`codigo/`](codigo/):

1. **Execute** o programa no [Google Colab](https://colab.research.google.com) ou no Python do seu computador.
2. **Teste** com respostas diferentes. Tente também respostas "erradas" para ver o que acontece.
3. **Pesquise** os comandos que você ainda não conhece.
4. **Explique com as suas palavras:**
   - O que o programa faz?
   - Como ele funciona, linha por linha?
   - Quais comandos novos você descobriu e para que servem?

## Dicas

- A mensagem de erro **não é inimiga**: leia a última linha, ela diz o que deu errado.
- Para pesquisar, use o nome do comando junto com "python", por exemplo: `python range`.
- Não precisa entender tudo de primeira. Anote suas dúvidas para trazer na próxima aula.
