## Objetivos

- Entender a internet como um "correio global": cada dispositivo tem um endereço único (IP)
- Diferenciar cliente e servidor e o ciclo pedido/resposta do HTTP
- Saber o que o DNS faz (a "lista telefônica" da web)
- Ler as partes de uma URL (protocolo, servidor, caminho)
- Conhecer os 3 pilares da web: HTML (estrutura), CSS (estilo) e JavaScript (ação)
- Gerar a primeira página HTML usando Python
